# Math Docs

## Initialize

1. Initialize with template

```text
typst init @preview/ilm:1.4.1 <DIR>
```

2. VScode formatter settings

```json
// settings.json
{
  // ...
  "tinymist.formatterMode": "typstfmt",
  "[typst]": {
    "editor.defaultFormatter": "myriad-dreamin.tinymist",
    "editor.formatOnSave": true
  }
}
```
